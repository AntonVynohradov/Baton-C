
# Class Hierarchy

This inheritance list is sorted roughly, but not completely, alphabetically:


* **struct** [**baton\_channel**](structbaton__channel.md) _Stop-and-wait state of the channel to one peer, both directions._ 
* **struct** [**baton\_frame**](structbaton__frame.md) _One decoded frame (header fields and payload, without SYNC and CRC)._ 
* **struct** [**baton\_link**](structbaton__link.md) _Link state._ 
* **struct** [**baton\_link\_config**](structbaton__link__config.md) _Link configuration passed to_ [_**baton\_link\_init**_](group__baton__link.md#function-baton_link_init) _._
* **struct** [**baton\_link\_counters**](structbaton__link__counters.md) _Link diagnostic counters._ 
* **struct** [**baton\_node**](structbaton__node.md) _Node state._ 
* **struct** [**baton\_node\_config**](structbaton__node__config.md) _Node configuration passed to_ [_**baton\_node\_init**_](group__baton__node.md#function-baton_node_init) _; copied._
* **struct** [**baton\_parser**](structbaton__parser.md) _Incremental parser state for one byte stream._ 
* **struct** [**baton\_queue**](structbaton__queue.md) _Queue state._ 
* **struct** [**baton\_record**](structbaton__record.md) _Header of one event record._ 
* **struct** [**baton\_stats**](structbaton__stats.md) _Diagnostic counters, see_ [_**baton\_node\_get\_stats()**_](group__baton__node.md#function-baton_node_get_stats) _._
* **struct** [**msg\_desc**](structmsg__desc.md) _Identifier and maximum length of one message._
