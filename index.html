    The problem

    One shared wire, no second chance

    A few microcontrollers share one UART line at 9600 bit/s. Two talking at once destroy each other's bytes, noise flips bits, a board is unplugged in the field — and a lost "stop" command is a bug report. The firmware has a few kilobytes of RAM, no operating system to lean on, and code that has to pass a review.

    Collisions, noise and dead nodes

    The master passes the baton: only the polled node transmits, for a bounded slot. CRC-16, acknowledgements, retries and duplicate filtering deliver every event exactly once; an unreachable node cannot eat the time of the others.

    Quick start

    A minimal slave in one file¶

    The application owns one struct baton_node, gives it a write function for the UART and a callback for received messages, passes every received byte from the UART interrupt and calls baton_node_process() every millisecond. This slave publishes its uptime as a state and acknowledges every CMD_SET_OUTPUT event with an OUTPUT_REPORT event.

    #include "baton.h"

static const uint8_t slaves[] = {0x11U, 0x12U};
static struct baton_node node;

static int uart_write(void* context, const uint8_t* data, size_t length)
{
    (void) context;
    return board_uart_write(data, length); /* start a non-blocking transmission */
}

static void on_message(void* context, uint8_t src, uint8_t msg_id, const uint8_t* data,
                       uint8_t length)
{
    (void) context;
    if ((msg_id == BATON_MSG_CMD_SET_OUTPUT) && (length == 2U))
    {
        (void) baton_node_send(&node, src, BATON_MSG_OUTPUT_REPORT, data, 2U, BATON_PRIO_HIGH);
    }
}

void uart_rx_irq_handler(uint8_t byte) /* called by the UART receive interrupt */
{
    baton_node_rx_isr(&node, byte);
}

int main(void)
{
    struct baton_node_config config;
    uint32_t next_status = 0U;

    baton_node_default_config(&config); /* 9600 bit/s, 250 ms slot, single-wire echo */
    config.own_address = 0x11U;
    config.master_address = 0x01U;
    config.slave_addresses = slaves;
    config.slave_count = 2U;
    config.write = uart_write;
    config.on_message = on_message;
    (void) baton_node_init(&node, &config, board_millis());

    for (;;)
    {
        const uint32_t now = board_millis();

        baton_node_process(&node, now);
        if ((int32_t) (now - next_status) >= 0)
        {
            uint8_t uptime[4];

            baton_put_u32le(uptime, now / 1000U);
            (void) baton_node_publish(&node, BATON_MSG_NODE_STATUS, uptime, 4U);
            next_status += 1000U;
        }
    }
}

    board_uart_write() and board_millis() stand for your board's UART driver and tick. The message lists (NODE_STATUS, CMD_SET_OUTPUT, OUTPUT_REPORT) come from baton_user_config.h, shared by every node of the bus. The examples are complete programs for bare metal, Zephyr and a PC serial port.
